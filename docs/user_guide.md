## 1. Регистрация и вход

### Регистрация

1. На экране входа нажмите ссылку **«Нет аккаунта? Зарегистрироваться»**.
2. Заполните поля:
   - **Email** (обязательное) — адрес электронной почты.
   - **Имя** (необязательное) — отображаемое имя (никнейм). Если не указано, будет использована часть email до символа `@`.
   - **Пароль** (обязательное) — пароль для входа.
3. Нажмите **«Зарегистрироваться»**.
4. После успешной регистрации вы будете автоматически добавлены как первый член семьи (с коэффициентом порции 1.0). Затем система вернёт вас на экран входа.

### Вход

1. Введите **Email** и **Пароль**.
2. Рядом с полем пароля есть значок глаза (👁) для переключения видимости пароля — нажмите его, чтобы показать или скрыть введённый текст.
3. Нажмите **«Войти»**.
4. При успешной авторизации откроется Планировщик меню.

### Выход

- **Десктоп:** нажмите кнопку **«Выйти»** в нижней части боковой панели.
- **Мобильные устройства:** перейдите в раздел **Настройки** (иконка в bottom navigation bar), перейдите в подраздел **«Настройки аккаунта»** и нажмите **«Выйти»**.

## 2. Навигация

### Десктоп

Слева расположена боковая панель с пунктами меню:

| Пункт             | Описание                     |
|--------------------|------------------------------|
| Планировщик        | Планирование меню на неделю  |
| Список покупок     | Просмотр и управление списком покупок |
| Рецепты            | Управление рецептами         |
| Продукты           | Управление продуктами        |
| Настройки          | Настройки приложения         |

Боковую панель можно свернуть/развернуть кнопкой **«Свернуть»** в её нижней части. В свёрнутом виде отображаются только иконки.

В нижней части боковой панели отображается имя текущего пользователя и кнопка выхода.

### Мобильные устройства

На мобильных устройствах навигация расположена в нижней части экрана в виде **bottom navigation bar** с иконками:
- **Меню** (Планировщик меню)
- **Покупки** (Список покупок)
- **Рецепты** (управление рецептами)
- **Продукты** (управление продуктами)
- **Настр.** (Настройки)

Bottom navigation bar прилипает к нижней части экрана и уважает безопасные зоны (notch, home indicator на устройствах с округлёнными краями).

На мобильных устройствах элементы интерфейса адаптированы для сенсорного взаимодействия:
- **Touch-friendly targets** — все интерактивные элементы имеют минимальный размер 40px для удобного нажатия.
- **Диалоги как bottom sheets** — модальные окна для подтверждения и ввода информации скользят вверх с нижней части экрана.
- **Responsive панели** — левая и правая боковые панели (где применимо) открываются как drawer-ы (модальные слои) вместо постоянного отображения.
- **Full-screen формы** — формы редактирования (рецепты, продукты) разворачиваются на весь экран с кнопкой возврата вместо крестика закрытия.

## 3. Продукты

Раздел **«Продукты»** содержит каталог всех продуктов, используемых в рецептах и меню.

### Список продуктов

- Таблица отображает все продукты с колонками: **Название**, **Категория**, **Ед. рец.** (единица в рецепте), **Ед. пок.** (единица покупки), **Цена**.
- **Поиск**: поле ввода над таблицей фильтрует продукты по названию.
- **Фильтр по категории**: выпадающий список рядом с поиском фильтрует продукты по выбранной категории. Вы можете выбрать одну категорию или несколько (множественный выбор) для отображения продуктов из всех выбранных категорий. По умолчанию отображаются все категории.
- **Сортировка**: все продукты автоматически отсортированы по названию в алфавитном порядке (А-Я). Нажмите на заголовок колонки **Название** для сортировки по убыванию (Я-А) и обратно.

#### Кнопки инструментов

- **«+ Новый продукт»** — создать новый продукт (см. раздел «Создание продукта»).
- **«Импорт»** — открывает диалоговое окно для импорта продуктов из файла (CSV или JSON). Импорт обновляет существующие записи или создаёт новые.
- **«Экспорт»** — открывает диалоговое окно для экспорта всех продуктов в выбранном формате (CSV или JSON) с возможностью скачать файл и пример шаблона.

На мобильных устройствах кнопки **«Импорт»** и **«Экспорт»** скрываются в dropdown меню (иконка **⋯** «Ещё»). Нажмите на неё, чтобы увидеть все доступные действия.

#### Выбор и массовое удаление

- **«Выбрать»** — включить режим выделения. Рядом с каждым продуктом появляются галочки.
- Флажок в заголовке таблицы выбирает/снимает выделение со всех товаров одновременно.
- Клик на строку или её галочку переключает выбор. Выделенные строки подсвечиваются синим фоном.
- **Счётчик** показывает **«Выбрано: N»** — количество выбранных товаров.
- **«Удалить выбранные»** — удаляет все выбранные товары. Требует подтверждения.
- **«Удалить все»** — удаляет все товары в списке. Видна только вне режима выделения, если список не пуст. Требует подтверждения.
- **«Отменить»** — выход из режима выделения и очистка выбора.
- При входе в режим выделения открытая форма редактирования закрывается.

### Создание продукта

1. Нажмите **«+ Новый продукт»**.
2. Откроется боковая панель с формой.

### Форма продукта

| Поле                   | Описание                                       | Обязательное |
|------------------------|-------------------------------------------------|:---:|
| Название               | Наименование продукта. Название должно быть уникальным в пределах вашего аккаунта — система не позволит создать продукт с названием, совпадающим с существующим. | Да  |
| Категория              | Категория продукта (из справочника)             | Да  |
| Бренд                  | Название бренда                                 | Нет |
| Поставщик              | Магазин или поставщик                           | Нет |
| Ед. в рецепте          | Единица измерения, используемая в рецептах      | Да  |
| Ед. покупки            | Единица измерения при покупке                   | Да  |
| Цена (руб.)            | Цена за единицу покупки                         | Нет  |
| Коэф. конвертации      | Коэффициент пересчёта из единиц рецепта в единицы покупки | Да |

**Доступные единицы измерения:** г (граммы), кг (килограммы), мл (миллилитры), л (литры), ч.л. (чайные ложки), ст.л. (столовые ложки), шт (штуки), кор (коробки), уп (упаковки).

**Пример коэффициента конвертации:** если в рецепте используются граммы, а покупка в килограммах, коэффициент конвертации = 1000 (1 кг = 1000 г).

**Автоматический расчёт коэффициента:** если вы выбираете единицы из одной группы измерений (вес: г/кг, объём: мл/л/ч.л./ст.л.), коэффициент пересчёта рассчитывается автоматически. Поле при этом становится недоступным для редактирования и отображает справку **«Рассчитан автоматически»**. Если единицы из разных групп (например, г и шт), поле остаётся редактируемым для ручного ввода.

### Редактирование и удаление

- Нажмите на строку продукта в таблице — откроется форма редактирования.
- Для сохранения изменений нажмите **«Сохранить»**.
- Для удаления нажмите **«Удалить»** и подтвердите действие в диалоговом окне.
- После сохранения или удаления боковая панель с формой автоматически закрывается.

### Ингредиенты

Раскрывающаяся секция **«Ингредиенты»**. В рецепте можно использовать два типа ингредиентов:

#### Продукты

Обычные продукты из каталога:

- **Продукт** — выбор из каталога продуктов. В выпадающем списке внизу (после разделителя) есть опция **«+ Создать новый продукт...»**. Нажмите её, чтобы создать новый продукт прямо из модального окна выбора ингредиентов. Откроется форма создания продукта. После сохранения новый продукт автоматически назначится текущему ингредиенту, единица измерения рецепта будет заполнена из настроек продукта (единица в рецепте), а количество установится по умолчанию (100 для граммов, 1 для остальных).
- **Проверка уникальности:** при создании или редактировании продукта система проверяет уникальность названия в пределах вашего аккаунта. Если продукт с таким названием уже существует, будет выведено сообщение об ошибке **«Продукт с таким названием уже существует»**. Это предотвращает создание дубликатов.
- **Количество** — числовое значение.
- **Единица** — подставляется автоматически из настроек продукта.

#### Рецепты-ингредиенты (вложенные рецепты)

Рецепт можно использовать как ингредиент внутри другого рецепта. Это полезно для сложных блюд, состоящих из нескольких компонентов (например, пирог с начинкой, где начинка — отдельный рецепт).

**Добавление рецепта-ингредиента:**

1. В кнопке **«+ Добавить»** нажмите стрелку справа и выберите опцию **«Рецепт-ингредиент»** (или просто нажмите на кнопку, если вы хотите добавить продукт).
2. Откроется новая строка с полями специально для рецепта.

**Настройка рецепта-ингредиента:**

- **Рецепт** — выпадающий список со всеми доступными рецептами. Система автоматически исключает текущий рецепт и рецепты, которые уже используют данный рецепт как ингредиент (защита от циклических зависимостей).
- **Количество** — числовое значение.
- **Единица измерения** — переключатель между двумя режимами:
  - **«порц.»** — использовать порции. Система рассчитает необходимое количество на основе стандартных порций выбранного рецепта.
  - **«г»** (граммы) — использовать граммы. При выборе этого режима система рассчитает масштаб как `указанные_граммы / вес_рецепта`. **Важно:** если рецепт-ингредиент не имеет указанного веса, появится ошибка: **«Укажите вес рецепта или используйте порции»**. В этом случае либо установите вес рецепта (поле «Вес готового блюда (г)» в его форме), либо переключитесь на режим порций.
- **→ (стрелка)** — кнопка навигации. Нажмите, чтобы быстро перейти к редактированию выбранного рецепта-ингредиента.

**Показать все продукты (для рецептов с подрецептами):**

Если рецепт содержит рецепты-ингредиенты и уже сохранён, под списком ингредиентов появляется блок **«Показать все продукты»**. Эта секция показывает полный список всех базовых продуктов, которые будут использованы при приготовлении, рекурсивно развёрнутые из вложенных рецептов.

- Нажмите **«Показать все продукты»**, чтобы раскрыть список.
- Рядом со ссылкой отображается кнопка обновления **(↻)** — она появляется, когда вы изменили ингредиенты после последнего расчёта. Нажмите её, чтобы пересчитать список продуктов на основе текущего (сохранённого) состояния ингредиентов.
- Кнопка обновления скрывается, когда список продуктов актуален.

#### Управление ингредиентами

Кнопка **«+ Добавить»** предоставляет доступ к модальному окну выбора ингредиентов **IngredientPickerModal** с удобным интерфейсом:

**Окно выбора ингредиентов:**
- **Две вкладки** — **«Продукты»** (обычные продукты из каталога) и **«Рецепты»** (рецепты-ингредиенты).
- **Поиск** — введите название продукта или рецепта для фильтрации списка.
- **Фильтр по категориям** — выпадающий список рядом с поиском позволяет отфильтровать по выбранной категории.
- **Множественный выбор** — нажимайте на элементы в списке для их выбора/снятия выбора. Выбранные элементы отмечены галочкой.
- **Добавление** — нажмите **«Добавить выбранные»**, и все отмеченные элементы будут добавлены в форму рецепта как ингредиенты за одно открытие модального окна.

**Порядок ингредиентов:** ингредиенты сохраняют порядок, в котором вы их расположили. При редактировании рецепта они отображаются в сохранённом порядке. При сохранении порядковые номера присваиваются автоматически.

**Удаление ингредиента:** нажмите **×** (крестик справа от каждой строки) — удалить этот конкретный ингредиент. Клик происходит без подтверждения.

### Шаги приготовления

Раскрывающаяся секция **«Шаги приготовления»**. Шаги отображаются нумерованным списком.

**Добавление шага:**
1. Введите описание шага в поле ввода.
2. Нажмите **«+»** или клавишу **Enter**.

**Редактирование шага:**
1. Наведите курсор на шаг — появится кнопка **✎**.
2. Нажмите на неё — текст станет редактируемым.
3. Внесите изменения и нажмите **Enter** или кликните за пределами поля для сохранения.

**Удаление шага:** нажмите **«−»** для удаления последнего шага.

### Сохранение и удаление

- **«Сохранить»** — сохраняет рецепт и закрывает панель.
- **«Удалить»** (только для существующих рецептов) — удаление с подтверждением.

## 5. Планировщик меню

Основной экран приложения. Позволяет составить меню на неделю, распределив блюда и продукты по дням и приёмам пищи.

### Структура экрана

#### Десктоп

Экран разделён на три области:

1. **Левая панель** — список сохранённых меню с вкладками для быстрого доступа к недавно использованным меню (вкладка **«История»**) и полный список всех меню (вкладка **«Все меню»**).
2. **Центральная область** — сетка планирования (7 дней × 3 приёма пищи) с оптимизированной отрисовкой для быстрой работы с большими меню.
3. **Правая панель** — панель-источник с рецептами и продуктами для перетаскивания.

На средних экранах левая и правая панели можно свернуть кнопками коллапса для экономии места.

#### Мобильные устройства

На мобильных устройствах панели открываются как **drawer-ы** (модальные слои):
- Кнопка в левом верхнем углу открывает **левый drawer** со списком меню.
- Кнопка в правом верхнем углу открывает **правый drawer** с рецептами и продуктами для добавления.

**PlannerGrid на мобильных устройствах:** сетка меню отображается в режиме **swipe-per-day** — вы видите один день за раз с горизонтальной прокруткой (CSS snap scroll). Тень-подсказка с боков экрана указывает на наличие дополнительного контента. Свайпайте влево/вправо, чтобы переместиться между днями.

**Добавление элементов на мобильных устройствах:** вместо drag-and-drop из боковой панели используется **MobileItemPicker** — bottom sheet (панель, выдвигаемая снизу экрана). Нажмите на ячейку меню, и откроется bottom sheet с вкладками **Блюда** и **Ингредиенты**. Выберите нужный элемент из списка.

### Управление меню

#### Создание нового меню

1. В левой панели нажмите **«+ Новое меню»**.
2. В диалоговом окне введите название меню.
3. Нажмите **«Подтвердить»**.

#### Выбор меню

Нажмите на название меню в левой панели. Сетка заполнится содержимым выбранного меню.

**Сортировка меню:** список сохранённых меню отображается от новых к старым (по убыванию id).

#### Удаление меню

Нажмите **«Удалить»** в левой панели и подтвердите действие.

### Сетка планирования

Сетка состоит из ячеек, где:

- **Столбцы** — дни недели: Пн, Вт, Ср, Чт, Пт, Сб, Вс.
- **Строки** — приёмы пищи: Завтрак, Обед, Ужин.

Сетка растягивается на всю доступную высоту экрана.

#### Добавление блюда или продукта в ячейку

**Десктоп и средние экраны:**

1. В правой панели выберите вкладку **«Блюда»** (рецепты) или **«Ингредиенты»** (продукты).
2. При необходимости используйте поиск для фильтрации списка.
3. Перетащите (drag & drop) нужный элемент в ячейку сетки.

**Мобильные устройства:**

1. Нажмите на ячейку сетки, в которую хотите добавить элемент.
2. Откроется **MobileItemPicker** — bottom sheet с вкладками **Блюда** и **Ингредиенты**.
3. Выберите нужный элемент из списка, используя поиск при необходимости, или выберите категорию в выпадающем списке для фильтрации по категории.
4. Нажмите на элемент для добавления в ячейку.

При добавлении:
- **Рецепт** — количество порций рассчитывается автоматически: суммируются коэффициенты порций всех членов семьи. Например, если в семье мама (×1.0), папа (×1.0) и ребёнок (×0.5), будет установлено 2.5 порции.
- **Продукт** — количество устанавливается равным 1 в единице рецепта продукта.

#### Отображение элементов в ячейке

Каждый элемент в ячейке отображается с цветовой маркировкой:
- **Рецепты** — голубой фон с синей полосой слева. Показывает название и количество порций (например, «2.5 п.»).
- **Продукты** — оранжевый фон с оранжевой полосой слева. Показывает название и количество с единицей (например, «1 г»).

#### Перемещение элементов между ячейками

Вы можете перетащить элемент из одной ячейки в другую (например, из Понедельника Завтрак в Среду Ужин). При наведении на целевую ячейку она подсвечивается синей границей. Элемент сохраняет все свои данные (количество, количество порций) при перемещении.

#### Сортировка элементов в ячейке

Вы можете перетащить элемент в пределах одной ячейки, чтобы изменить его порядок. При перетаскивании элемент отображается с прозрачностью (ghost эффект). Порядок сохраняется при сохранении меню.

#### Изменение количества

Нажмите на элемент в ячейке — откроется диалог:
- Для рецептов: **«Порции»** — введите нужное количество порций.
- Для продуктов: **«Количество»** — введите нужное количество. Рядом с полем ввода отображается единица измерения продукта в рецепте (г, шт, кг и т.д.).

**Стартовое количество при добавлении:** при добавлении продукта с единицей измерения **«г»** (граммы) система автоматически устанавливает стартовое количество **100 г** для удобства. Для остальных единиц стартовое количество равно 1.

#### Удаление элемента из ячейки

Наведите курсор на элемент и нажмите кнопку **×** справа.

### Панель-источник (правая)

#### Информация о семье

В верхней части правой панели отображается состав семьи с коэффициентами порций:
```
• Мама (×1)
• Папа (×1)
• Ребёнок (×0.5)
```

#### Вкладки

- **Блюда** — список всех рецептов. Перетаскивайте в ячейки сетки.
- **Ингредиенты** — список всех продуктов. Перетаскивайте в ячейки сетки.

Каждая вкладка имеет поле поиска для фильтрации списка. Под полем поиска расположен выпадающий список **«Все категории»** для фильтрации по категориям. Вы можете выбрать несколько категорий сразу для отображения рецептов/продуктов из всех выбранных категорий. При переключении вкладки фильтр сбрасывается.

### Действия с меню

#### Десктоп

Кнопки под сеткой:

| Кнопка                          | Действие                                           |
|---------------------------------|----------------------------------------------------|
| Сохранить                       | Сохраняет текущее меню (на мобильных автосохранение происходит автоматически)                              |
| Очистить                        | Удаляет все элементы из сетки (с подтверждением)    |
| Скачать                         | Объединённая кнопка с выпадающим меню для импорта и экспорта меню. Нажмите на стрелку, чтобы выбрать: **Импорт** (загрузка меню из JSON-файла), **Экспорт** (сохранение текущего меню в JSON-файл с примером шаблона) или **PDF** (экспорт в PDF для печати). Активна только когда выбрано меню. |
| Копировать                      | Дублирует текущее меню с сохранением всех рецептов и их количеств. Новому меню присваивается название исходного меню с суффиксом (например, «Меню 1 (копия)»). |
| Обзор блюд                       | Переходит на экран сводки блюд для просмотра всех рецептов, выбора приёмов пищи и экспорта плана приготовления. |
| Сформировать список покупок      | Генерирует список покупок и переходит к нему        |

#### Мобильные устройства

На мобильных устройствах в заголовке появляется кнопка с тремя точками **⋮** (kebab меню). При нажатии открывается выпадающее меню с действиями:

| Действие                         | Описание                                          |
|----------------------------------|---------------------------------------------------|
| Обзор блюд                       | Переходит на экран сводки блюд                    |
| Сформировать список покупок      | Генерирует список покупок                         |
| Очистить меню                    | Удаляет все элементы из сетки (с подтверждением) |
| Импорт                           | Загружает меню из JSON-файла                      |
| Экспорт                          | Сохраняет текущее меню в JSON-файл               |

Кнопки действий в нижней части сетки планировщика теперь видны только на десктопе. На мобильных устройствах используется kebab меню в заголовке.

### Контекстное меню и взаимодействие с элементами

#### Контекстное меню элемента в сетке

Нажмите **правой кнопкой мыши** на элемент (рецепт или продукт) в ячейке сетки — появится контекстное меню с доступными действиями:
- **Копировать** — скопировать содержимое элемента в буфер обмена.
- **Вставить** — вставить содержимое из буфера обмена в текущую ячейку (если элемент был скопирован).
- **Удалить** — удалить элемент из ячейки.

#### Копирование и вставка между ячейками

Вы можете скопировать элемент из одной ячейки и вставить его в другую:
1. Нажмите **правой кнопкой мыши** на элемент и выберите **«Копировать»**.
2. Нажмите **правой кнопкой мыши** на целевую ячейку и выберите **«Вставить»**.
3. При вставке сохраняются все параметры элемента (количество, порции).

#### Сохранение состояния при навигации

При переходе в другие разделы приложения (Рецепты, Продукты, Настройки) и возврате обратно в **Планировщик меню**:
- **Выбранное меню** остаётся активным (не требуется повторный выбор).
- **Состояние сетки** сохраняется (все добавленные элементы и их расположение).
- **Панели** сохраняют свой статус (развёрнуты или свёрнуты на средних экранах).

#### Автоматическое создание меню

Если при работе в сетке меню вы добавляете элемент (рецепт или продукт) в ячейку, но ни одного меню не выбрано, система автоматически создаст новое меню с стандартным названием (например, «Меню 1»). После этого элемент будет добавлен в созданное меню.

#### Удаление элементов на мобильных устройствах

На мобильных устройствах при нажатии на ячейку сетки открывается **MobileItemPicker** (bottom sheet для добавления элементов). В этом же bottom sheet вы можете удалять уже добавленные элементы:
- Нажмите **×** рядом с элементом в списке, чтобы удалить его из ячейки.
- Это избавляет от необходимости закрывать окно и искать элемент для удаления.

## 6. Экран сводки блюд

Экран сводки блюд позволяет просмотреть сводку всех блюд и продуктов, выбранных в текущем меню, с удобным форматом для проверки и экспорта плана приготовления.

### Открытие экрана сводки

В Планировщике меню (на панели действий внизу экрана на десктопе или в меню действий на мобильных устройствах) нажмите кнопку **«Сводка»** или **«Посмотреть сводку»** — откроется экран сводки блюд для текущего выбранного меню.

### Структура экрана сводки

Экран разделён на три основных раздела:

#### 1. Заголовок (SummaryHeader)

Отображает название текущего меню и количество выбранных блюд (рецептов и вложенных рецептов). Рядом показаны фильтры для быстрого просмотра (если применены).

#### 2. Основное содержимое

**Раздел 1: Рецепты (основные блюда)**

Каждый рецепт отображается как **карточка** с информацией:

- **Заголовок карточки:**
  - **Название рецепта**
  - **Трёхуровневый чекбокс:**
    - **Выбраны все приёмы пищи** — чекбокс полностью отмечен (синий галочка).
    - **Выбраны некоторые приёмы пищи** — чекбокс частично отмечен (синий квадрат с минусом).
    - **Ничего не выбрано** — чекбокс не отмечен (пустой квадрат).
  - **Количество порций и штук** — для рецептов в штучном режиме (если задано) отображается в формате **«X порц. · Y шт»**. Для обычных рецептов показывается только количество порций (например, **«2.5 п.»**).

- **Раскрывающаяся секция приёмов пищи:**

  Нажмите на карточку или на иконку раскрытия — откроется список приёмов пищи, в которых используется этот рецепт:

  - Каждый приём пищи отображается как **чип (chip)** с информацией:
    - **Название приёма пищи** (например, **«Пн - Завтрак»**, **«Ср - Обед»**).
    - **Количество порций и штук** — в том же формате, что и в заголовке карточки (например, **«2 порц. · 6 шт»** или просто **«1.5 п.»**).
    - **Чекбокс выбора** — рядом с каждым чипом расположен чекбокс. Отметьте его, чтобы включить этот приём пищи в список покупок.

  - Под чипсами расположена **секция ингредиентов** этого рецепта:
    - Показывается список всех ингредиентов с **масштабированными количествами** на основе выбранных приёмов пищи.
    - Для каждого ингредиента отображается: **Название** и **Количество с единицей** (например, **«Мука: 500 г»**, **«Молоко: 1 л»**).

- **Управление выбором:**
  - Нажмите на чекбокс в заголовке карточки, чтобы **выбрать/отменить выбор всех приёмов пищи** для этого рецепта.
  - Нажмите на чекбокс рядом с конкретным чипом приёма пищи, чтобы выбрать/отменить только этот приём.

**Раздел 2: Вложенные рецепты (подрецепты)**

Если в меню используются рецепты-ингредиенты (вложенные рецепты), они отображаются в отдельном разделе **«Вложенные рецепты»**:

- **Структура аналогична основным рецептам:**
  - Название, трёхуровневый чекбокс, общее количество (порций или граммов в зависимости от режима вложенного рецепта).
  - Раскрывающаяся секция со списком приёмов пищи, в которых используется этот подрецепт.
  - Список ингредиентов с масштабированными количествами.

- **Особенность:** для подрецептов также отображается их **тип масштабирования** (по порциям или по граммам).

**Раздел 3: Агрегированные отдельные продукты**

Если в меню добавлены **отдельные продукты** (не входящие в рецепты), они отображаются в отдельном разделе **«Отдельные продукты»**:

- Каждый продукт представлен как **карточка** с:
  - **Название продукта**
  - **Общее количество** (сумма по всем приёмам пищи)
  - **Раскрывающаяся секция** со списком приёмов пищи, в которых используется этот продукт (как чипы с количествами).
  - **Чекбокс выбора** аналогично рецептам.

#### 3. Подвал (SummaryFooter)

В нижней части экрана расположена **кнопка-действие:**

- **«Сформировать список покупок»** — генерирует отфильтрованный список покупок на основе **выбранных приёмов пищи, рецептов и подрецептов**. При нажатии система переходит на страницу списков покупок с новым сгенерированным списком.

### Экспорт плана приготовления

На экране сводки расположена **кнопка «Скачать план»** (обычно в верхней части экрана или в меню действий на мобильных устройствах). Нажмите на неё — откроется **модальное окно экспорта (SummaryExportModal)**.

#### Модальное окно экспорта

**Содержимое модального окна:**

- **Заголовок:** «Экспорт плана приготовления»
- **Основная область:** содержит полный текст плана приготовления в формате техкарты кухни.

**Структура текста плана:**

Формат структурирован для удобства кухни:

```
РЕЦЕПТЫ
═══════════════════════════════════════

Понедельник - Завтрак: Блины (2 порц. · 8 шт)
  Ингредиенты:
  • Мука: 200 г
  • Молоко: 400 мл
  • Яйца: 2 шт

Вторник - Обед: Борщ (3 порц.)
  Ингредиенты:
  • Свёкла: 600 г
  • Капуста: 500 г
  • Мясо: 900 г

...

ВЛОЖЕННЫЕ РЕЦЕПТЫ
═══════════════════════════════════════

Дрожжевое тесто (0.5 кг)
  Ингредиенты:
  • Мука: 250 г
  • Молоко тёплое: 125 мл

...

ОТДЕЛЬНЫЕ ПРОДУКТЫ
═══════════════════════════════════════

Понедельник - Завтрак: Хлеб (300 г)
Среда - Обед: Сливочное масло (50 г)

...
```

**Кнопки действия в модали:**

- **«Копировать»** — копирует весь текст плана в буфер обмена. После нажатия появляется уведомление **«Скопировано в буфер обмена»** с коротким анимированным тостом, подтверждающим успех.
- **«Скачать»** — скачивает текст плана в файл **`meal_plan.txt`**. Файл содержит ту же информацию в текстовом формате, готовом к печати или редактированию.
- **«Закрыть»** или нажатие вне модали — закрывает окно без действий.

### Примеры использования

#### Пример 1: Проверка меню перед списком покупок

1. В Планировщике меню выберите недельное меню.
2. Нажмите **«Сводка»**.
3. На экране сводки просмотрите все блюда и их ингредиенты.
4. Если нужно исключить какой-либо приём пищи (например, ужин в выходные день), снимите его галочку в чипсе.
5. Нажмите **«Сформировать список покупок»** — будет создан список только для выбранных приёмов пищи.

#### Пример 2: Экспорт плана для кухни

1. Подготовьте сводку блюд (см. выше).
2. Нажмите **«Скачать план»**.
3. В модали нажмите **«Скачать»** — файл `meal_plan.txt` будет сохранён на компьютер.
4. Откройте файл в текстовом редакторе, распечатайте и повесьте на кухню для удобства приготовления.

## 7. Список покупок

Формируется автоматически из выбранного меню. Содержит все необходимые продукты с расчётом количества и стоимости.

### Формирование списка

В Планировщике меню нажмите **«Сформировать список покупок»**. Приложение автоматически:
- соберёт все ингредиенты из рецептов с учётом количества порций;
- сгруппирует одинаковые продукты, суммируя количества;
- пересчитает количества из единиц рецепта в единицы покупки;
- рассчитает стоимость каждой позиции и итоговую сумму.

### Таблица покупок

#### Группировка товаров

Таблица поддерживает несколько вариантов группировки:

**По умолчанию — По категориям:** продукты сгруппированы по категориям для удобства покупок в разных отделах магазина.

**По поставщику:** альтернативный вариант группировки, при котором товары объединяются по полю **«Поставщик»** продукта. Товары без указанного поставщика попадают в группу **«Без поставщика»**. Это удобно, если вы закупаете товары у разных продавцов.

Выбор варианта группировки настраивается в разделе **Настройки → Настройки списка покупок** (см. раздел 9.5).

#### Отображение товаров

Для каждого продукта отображается:
- **Флажок** — отметка о покупке.
- **Название** — наименование продукта.
- **Количество** — в единицах покупки. Если продукт используется в рецептах, единицы рецепта отображаются в скобках (например, **«0.5 кг (500 г)»**, где 0.5 кг — закупочное количество, 500 г — рецептурное количество).
- **Стоимость** — расчётная стоимость в рублях.

#### Скрытие купленных товаров

На экране списка покупок доступна функция скрытия уже купленных товаров:

**На десктопе:** в панели действий заголовка расположена кнопка-иконка глаза **👁**. Нажмите её, чтобы скрыть/показать товары, отмеченные как купленные.

**На мобильных устройствах:** в kebab меню (три точки **⋮**) в заголовке экрана есть переключатель **«Скрыть/Показать купленные»** с иконкой глаза. Выберите действие, чтобы скрыть или показать купленные товары.

Состояние скрытия сохраняется в localStorage, поэтому при возврате на экран список покупок будет отображаться в том же состоянии.

#### Купленные товары в отдельной секции

Купленные товары группируются в отдельную секцию **«Куплено»** в конце таблицы. Эта секция:
- Отображается со значком галочки **✓** в заголовке.
- Стилизована светлее (фон `bg-slate-100`, серый текст) для визуального отличия от активных товаров.
- Упорядочивает купленные товары в конце списка для удобства.

#### Отметка о покупке

Нажмите флажок слева от продукта для отметки о покупке. Купленные позиции автоматически перемещаются в секцию **«Куплено»** в конце таблицы и отображаются зачёркнутым текстом с более светлым фоном.

#### Изменение количества

Нажмите на ячейку количества — откроется диалог редактирования.

#### Выбор и массовое удаление

- **«Выбрать»** — включить режим выделения. Рядом с каждым товаром появляются галочки.
- Флажок в заголовке таблицы выбирает/снимает выделение со всех товаров одновременно.
- Клик на строку или её галочку переключает выбор. Выделенные строки подсвечиваются синим фоном.
- **Счётчик** показывает **«Выбрано: N»** — количество выбранных товаров.
- **«Удалить выбранные»** — удаляет все выбранные товары из списка. Требует подтверждения.
- **«Удалить все»** — очищает весь список покупок. Видна только вне режима выделения, если список не пуст. Требует подтверждения.
- **«Отменить»** — выход из режима выделения и очистка выбора.

### Сохранение изменений

Кнопка **«Сохранить»** в заголовке экрана списка покупок всегда видима:
- **Когда нет изменений** — кнопка отображается серой и неактивной.
- **Когда есть несохранённые изменения** — кнопка становится синей и активной, позволяя сохранить изменения.

### Итоги и экспорт

#### Десктоп

Информация и действия располагаются в **правой панели**:

**Сумма корзины:**
- Общая стоимость всех позиций.
- Количество позиций в списке.
- Прогресс покупок: полоса прогресса с числом купленных позиций из общего количества.

**Дополнительные действия:**

| Кнопка                  | Действие                                                    |
|-------------------------|-------------------------------------------------------------|
| Удалить из списка        | Удаляет выбранный продукт из списка (с подтверждением)       |
| Экспорт                  | Единая кнопка с выпадающим меню для выбора формата экспорта: **Текст** (скачивает `shopping_list.txt`), **CSV** (скачивает `shopping_list.csv`), **JSON** (скачивает `shopping_list.json`) или **PDF** (скачивает `shopping_list.pdf` для печати). Все форматы содержат оба варианта количества: закупочное и рецептурное. Формирование файлов происходит на клиентской стороне без обращения к серверу. |

**Добавление продукта вручную:**

В секции **«Добавить продукт»** правой панели:
1. Выберите продукт из выпадающего списка.
2. Укажите количество.
3. Нажмите **«Добавить в список»**.

#### Мобильные устройства

На мобильных устройствах информация отображается иначе:

**Floating summary bar:** в нижней части экрана над bottom navigation bar отображается **плавающая сводка** со следующей информацией:
- Общая стоимость.
- Количество позиций и прогресс покупок (полоса прогресса).

**Bottom sheet для действий:** нажмите на floating summary bar, и откроется **slide-up bottom sheet** с полным содержимым:
- Информация о стоимости и прогрессе.
- Кнопка экспорта с выпадающим меню для выбора формата (**Текст**, **CSV**, **JSON** или **PDF**).
- Секция **«Добавить продукт»** с выпадающим списком и кнопкой добавления.

**Добавление продукта вручную на мобильных устройствах:**

1. Откройте bottom sheet, нажав на floating summary bar.
2. Прокрутите вниз до секции **«Добавить продукт»**.
3. Выберите продукт из выпадающего списка.
4. Укажите количество.
5. Нажмите **«Добавить в список»**.

#### Kebab меню на мобильных устройствах

На мобильных устройствах в заголовке экрана списка покупок появляется кнопка с тремя точками **⋮** (kebab меню). При нажатии открывается выпадающее меню с действиями:

| Действие                         | Описание                                          |

| Удалить выбранные               | Удаляет все выбранные товары из списка           |

## 8. Сохранённые списки покупок

Сохранённые списки позволяют создавать и переиспользовать списки покупок без необходимости каждый раз формировать их заново из меню.

### Боковая панель сохранённых списков

На странице **«Список покупок»** слева расположена панель **«Списки покупок»** со списком всех сохранённых списков текущего пользователя.

**Сортировка списков:** список сохранённых списков покупок отображается от новых к старым (по убыванию `created_at`).

**Кнопка создания:** нажмите кнопку **«+»** в строке заголовка панели (синяя кнопка) для создания нового пустого списка.

**Выбор списка:** нажмите на название списка в панели для его выбора. Выбранный список загружается в основную таблицу справа.

**Индикатор выбранного списка:** выбранный список подсвечивается (голубой фон или другой визуальный индикатор в зависимости от темы).

**Пустой список:** если нет ни одного сохранённого списка, панель отображает сообщение **«Нет сохранённых списков»** с кнопкой для создания первого списка или указанием, что список можно сформировать в планировщике меню.

### Операции со списками

#### Переименование списка

1. В панели сохранённых списков нажмите на три точки **⋯** (иконка меню) рядом с названием списка.
2. Выберите **«Переименовать»**.
3. Введите новое название.
4. Нажмите **«ОК»** или подтвердите клавишей Enter.

#### Копирование списка

1. В панели сохранённых списков нажмите на три точки **⋯** рядом с названием списка.
2. Выберите **«Копировать»**.
3. Система создаст новый список с копией всех товаров и статусов из оригинального списка. Название скопированного списка формируется автоматически (например, **«Исходный список (копия)»**).

#### Удаление списка

1. В панели сохранённых списков нажмите на три точки **⋯** рядом с названием списка.
2. Выберите **«Удалить»**.
3. Система запросит подтверждение удаления (**«Удалить список покупок?»**).
4. Нажмите **«Удалить»** для подтверждения или **«Отмена»** для отмены действия.

### Работа с товарами в сохранённом списке

Сохранённые списки работают так же, как и временные списки, сформированные из меню:

- **Отметка о покупке:** нажмите флажок слева от товара для отметки как купленного. Статус сохраняется автоматически.
- **Изменение количества:** нажмите на ячейку количества для редактирования. Введите новое значение и подтвердите.
- **Удаление товара:** используйте контекстное меню или режим выделения (см. раздел «Выбор и массовое удаление» выше).
- **Добавление товара:** используйте секцию **«Добавить продукт»** на боковой панели или в bottom sheet на мобильных устройствах.

### Формирование списка из меню

При нажатии на **«Сформировать список покупок»** в Планировщике меню система автоматически создаёт и сохраняет новый список. Сохранённый список связан с исходным меню и содержит полную информацию о товарах и их количествах. Этот список затем отображается в панели **«Списки покупок»** на странице списков.

## 9. Настройки

Раздел настроек доступен через боковую панель. Содержит следующие подразделы:

### 9.1. Члены семьи

Управление составом семьи. Коэффициенты порций членов семьи используются для автоматического расчёта количества порций при добавлении рецепта в меню.

| Поле                 | Описание                                              | Обязательное |
|----------------------|-------------------------------------------------------|:---:|
| Имя                  | Имя члена семьи                                       | Да  |
| Коэф. порции         | Множитель порции (1.0 — стандарт, 0.5 — половина, 2.0 — двойная) | Да |
| Ограничения          | Диетические ограничения (произвольный текст)           | Нет |
| Комментарий          | Дополнительные заметки                                 | Нет |

Диапазон коэффициента порции: от 0.1 до 5.0, шаг 0.1.

При регистрации нового пользователя автоматически создаётся первый член семьи с его именем и коэффициентом порции 1.0.

**Мобильные устройства:** на мобильных устройствах члены семьи отображаются в виде **карточек** вместо таблицы для лучшей читаемости и удобства взаимодействия.

### 9.2. Категории продуктов

Справочник категорий для организации продуктов (например: «Молочные», «Мясо», «Крупы»).

На мобильных устройствах категории отображаются в виде **карточек** вместо таблицы.

**Создание:** нажмите **«+ Добавить»** и введите название.

**Скрытие активной категории:**
- Нажмите **«Скрыть»** рядом с категорией.
- Требует подтверждения.
- Скрытая категория получает статус **«Скрыта»** и перестаёт отображаться в выпадающих списках при создании новых продуктов.

**Удаление:**
- Если категория не используется в продуктах или рецептах — удаляется полностью.
- Если категория используется — появляется специальное диалоговое окно **«Категория используется»** с сообщением **«Эта категория привязана к записям. Что сделать?»** и тремя вариантами:
  - **«Отмена»** — отменить операцию.
  - **«Скрыть»** — категория скрывается; существующие товары сохранят её, но новые товары не смогут её использовать.
  - **«Удалить полностью»** — категория удаляется окончательно.

**Восстановление:** скрытая категория (статус «Скрыта») может быть восстановлена кнопкой **«Активировать»**.

### 9.3. Категории рецептов

Аналогично категориям продуктов, но для рецептов (например: «Супы», «Выпечка», «Салаты»).

На мобильных устройствах категории отображаются в виде **карточек** вместо таблицы.

Поддерживает те же операции:
- **Скрытие активной категории** через кнопку **«Скрыть»** с подтверждением.
- **Удаление** с автоматическим выбором типа операции в зависимости от использования категории.
- **Восстановление** скрытой категории кнопкой **«Активировать»**.

### 9.4. Настройки аккаунта

#### Смена пароля

1. Введите **текущий пароль**.
2. Введите **новый пароль** (минимум 6 символов).
3. **Повторите новый пароль** — должен совпадать.
4. Нажмите **«Сменить пароль»**.

При неверном текущем пароле отобразится сообщение об ошибке.

### 9.5. Настройки списка покупок

Раздел настроек для управления поведением экрана списка покупок.

**Как открыть:** перейдите в **Настройки** → **Настройки списка покупок**.

#### Скрытие купленных товаров

**Переключатель:** «Скрывать купленные товары»

Когда эта опция включена, товары, отмеченные как купленные, автоматически скрываются из таблицы списка покупок. Это помогает сосредоточиться на товарах, которые ещё нужно купить.

**Состояние сохраняется** в localStorage, поэтому при возврате на экран список покупок будет отображаться в том же состоянии скрытия.

#### Способ группировки товаров

**Выбор группировки** (radio buttons):
- **По категории** (по умолчанию) — товары группируются по их категориям.
- **По поставщику** — товары группируются по полю **«Поставщик»** продукта. Товары без указанного поставщика попадают в группу **«Без поставщика»**.

Выбранный способ группировки применяется ко всем спискам покупок и сохраняется в localStorage.

## 10. Импорт и экспорт данных

Приложение поддерживает импорт и экспорт данных для продуктов, рецептов и меню. Эта функция позволяет создавать резервные копии, обмениваться данными между пользователями, или использовать готовые наборы рецептов и продуктов.

### Поддерживаемые форматы

- **CSV** — текстовый формат с запятыми. Удобен для редактирования в электронных таблицах (Excel, Google Sheets).
- **JSON** — структурированный формат с поддержкой сложных данных. Для рецептов доступен компактный вариант.

### Импорт данных

#### Запуск импорта

1. Перейдите в раздел (Продукты, Рецепты или Планировщик меню).
2. Нажмите кнопку **«Импорт»**.
3. В диалоговом окне выберите файл на диске.
4. Приложение загрузит данные.

#### Результат импорта

После импорта отобразится сообщение:
- **«Создано: N, Обновлено: N»** — количество созданных и обновлённых записей.
- Если возникли ошибки, они будут перечислены в диалоговом окне.

#### Логика обновления

- Если в загружаемом файле есть продукт/рецепт с названием, совпадающим с существующим, система обновит существующую запись.
- Иначе будет создана новая запись.

### Экспорт данных

#### Запуск экспорта

1. Перейдите в раздел (Продукты, Рецепты или Планировщик меню).
2. Нажмите кнопку **«Экспорт»**.
3. В диалоговом окне выполните следующие шаги:

#### Экспортные диалоги

**Форма экспорта содержит:**

- **Выбор формата** — переключатель для выбора CSV или JSON.
- **Компактный формат (только для рецептов JSON)** — опциональная галочка. При включении экспортирует рецепты без шагов приготовления и категорий (только базовые данные: название, ингредиенты, порции).
- **«Скачать пример»** — кнопка для скачивания примера файла в выбранном формате. Полезна как шаблон для создания собственного файла импорта.
- **«Скачать»** — скачивает экспортированный файл на диск. Файлы именуются как:
  - `products.csv` или `products.json` — для продуктов
  - `recipes.csv` или `recipes.json` — для рецептов
  - `menus.json` — для меню

#### Специфика по разделам

**Продукты:**
- Экспорт в CSV и JSON
- Содержит: название, категория, бренд, поставщик, единицы измерения, цену, коэффициент конвертации

**Рецепты:**
- Экспорт в CSV и JSON
- Содержит: название, категория, количество порций, вес готового блюда, ингредиенты (названия, количества, единицы), шаги приготовления
- Компактный JSON (опция) — экспортирует только базовые данные без шагов и категорий

**Меню:**
- Экспорт только в JSON
- Содержит: название меню, структуру сетки (день недели × приём пищи), рецепты и продукты с количествами
- Импорт меню возможен только при выборе существующего меню (кнопка «Импорт» активна после выбора меню в левой панели)

### Работа с примерами

Кнопка **«Скачать пример»** в диалоге экспорта загружает образец файла в выбранном формате. Это полезно для понимания структуры данных и создания собственных файлов импорта без использования приложения.

## 11. Типичные сценарии использования

### Сценарий 1: Первоначальная настройка

1. Зарегистрируйтесь в приложении.
2. Перейдите в **Настройки (раздел 7) → Члены семьи**. Ваш аккаунт уже добавлен как первый член семьи. Добавьте остальных членов семьи с нужными коэффициентами порций.
3. Перейдите в **Настройки → Категории продуктов** и создайте категории (например: «Молочные», «Мясо», «Овощи», «Крупы»).
4. Перейдите в **Настройки → Категории рецептов** и создайте категории (например: «Супы», «Вторые блюда», «Салаты», «Выпечка»).
5. Перейдите в **Продукты (раздел 3)** и добавьте продукты с указанием единиц измерения, цен и коэффициентов конвертации.
6. Перейдите в **Рецепты (раздел 4)** и создайте рецепты, добавив ингредиенты из каталога продуктов и шаги приготовления.

### Сценарий 2: Планирование меню на неделю

1. Откройте **Планировщик меню (раздел 5)**.
2. Нажмите **«+ Новое меню»** и введите название (например, «Неделя 12 марта»).
3. Из правой панели перетащите рецепты и продукты в нужные ячейки сетки (день недели × приём пищи).
4. Порции рассчитаются автоматически на основе состава семьи. При необходимости скорректируйте количество, нажав на элемент в ячейке.
5. Нажмите **«Сохранить»**.

### Сценарий 3: Формирование списка покупок

1. В Планировщике меню выберите нужное меню.
2. Нажмите **«Сформировать список покупок»**.
3. Приложение рассчитает все необходимые продукты, сгруппирует их по категориям и посчитает стоимость.
4. При необходимости добавьте дополнительные продукты вручную.
5. Экспортируйте список в текстовый формат или CSV (раздел 6) для удобства использования в магазине.
6. Во время покупок отмечайте купленные позиции флажком.

### Сценарий 4: Повторное использование меню

1. Откройте **Планировщик меню (раздел 5)**.
2. В левой панели выберите ранее сохранённое меню.
3. При необходимости внесите изменения (замените блюда, скорректируйте порции).
4. Сформируйте новый список покупок.

### Сценарий 5: Импорт готовых рецептов и продуктов

1. Если у вас есть файл с рецептами или продуктами (CSV или JSON), откройте раздел **Рецепты (раздел 4)** или **Продукты (раздел 3)**.
2. Нажмите кнопку **«Импорт»**.
3. Выберите файл на диске.
4. После успешного импорта система создаст новые записи или обновит существующие.

## 11. Штучный режим рецептов

Некоторые рецепты удобнее планировать по количеству штук, а не порций — например, печенье, котлеты, пирожки или блины. Для таких случаев предназначен **штучный режим**.

### Настройка рецепта в штучном режиме

1. Откройте форму создания или редактирования рецепта (раздел **Рецепты**).
2. Найдите переключатель **«Считать в штуках»** и включите его.
3. Заполните два новых поля:
   - **Количество штук** — сколько всего штук получается из рецепта (например, 24 печенья).
   - **Штук на порцию** — сколько штук составляет одну порцию (например, 4 печенья).
4. Поле **«Порции»** заполнится автоматически на основе введённых данных (24 ÷ 4 = 6 порций).
5. Сохраните рецепт.

> **Ограничения:**
> - Количество штук на порцию не может превышать общее количество штук.
> - Оба поля обязательны при включённом штучном режиме.

### Отображение в планировщике меню

Для рецептов в штучном режиме ячейка сетки меню показывает количество в формате **«X п. · Y шт»** — например, «3 п. · 12 шт» означает 3 порции, что соответствует 12 штукам.

### Редактирование количества штук в слоте

При добавлении рецепта в штучном режиме в ячейку планировщика можно указать нестандартное количество штук для этого конкретного слота:

1. Нажмите на ячейку с рецептом в штучном режиме.
2. Откроется диалог **«Количество: <Название рецепта>»**.
3. Поле **«Порции (авто)»** отображается только для справки и не редактируется.
4. В поле количества штук введите нужное значение.
5. Нажмите **«Сохранить»**.

### Экспорт и импорт рецептов в штучном режиме

Штучные поля (`total_pieces`, `pieces_per_portion`) включаются в экспорт рецептов в форматах CSV и JSON. При импорте эти поля опциональны — файлы без них импортируются корректно (рецепт создаётся без штучного режима).
