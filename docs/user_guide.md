# Руководство пользователя Menutor

Menutor — веб-приложение для планирования семейного меню на неделю, управления рецептами и продуктами, автоматического формирования списков покупок с расчётом стоимости.

## 1. Регистрация и вход

### Регистрация

1. На экране входа нажмите ссылку **«Нет аккаунта? Зарегистрироваться»**.
2. Заполните поля:
   - **Email** (обязательное) — адрес электронной почты.
   - **Имя** (необязательное) — отображаемое имя (никнейм). Если не указано, будет использована часть email до символа `@`.
   - **Пароль** (обязательное) — пароль для входа.
3. Нажмите **«Зарегистрироваться»**.
4. После успешной регистрации вы будете автоматически добавлены как первый член семьи (с коэффициентом порции 1.0). Затем система вернёт вас на экран входа.

### Вход

1. Введите **Email** и **Пароль**.
2. Нажмите **«Войти»**.
3. При успешной авторизации откроется Планировщик меню.

### Выход

Нажмите кнопку **«Выйти»** в нижней части боковой панели (на десктопе) для выхода из аккаунта.

## 2. Навигация

### Десктоп

Слева расположена боковая панель с пунктами меню:

| Пункт             | Описание                     |
|--------------------|------------------------------|
| Планировщик        | Планирование меню на неделю  |
| Список покупок     | Просмотр и управление списком покупок |
| Рецепты            | Управление рецептами         |
| Продукты           | Управление продуктами        |
| Настройки          | Настройки приложения         |

Боковую панель можно свернуть/развернуть кнопкой **«Свернуть»** в её нижней части. В свёрнутом виде отображаются только иконки.

В нижней части боковой панели отображается имя текущего пользователя и кнопка выхода.

### Мобильные устройства

На мобильных устройствах навигация расположена в нижней части экрана в виде панели с иконками: Меню, Покупки, Рецепты, Продукты, Настр.

## 3. Продукты

Раздел **«Продукты»** содержит каталог всех продуктов, используемых в рецептах и меню.

### Список продуктов

- Таблица отображает все продукты с колонками: **Название**, **Категория**, **Ед. рец.** (единица в рецепте), **Ед. пок.** (единица покупки), **Цена**.
- **Поиск**: поле ввода над таблицей фильтрует продукты по названию.
- **Сортировка**: нажмите на заголовок колонки для сортировки по возрастанию/убыванию.

#### Выбор и массовое удаление

- **«Выбрать»** — включить режим выделения. Рядом с каждым продуктом появляются галочки.
- Флажок в заголовке таблицы выбирает/снимает выделение со всех товаров одновременно.
- Клик на строку или её галочку переключает выбор. Выделенные строки подсвечиваются синим фоном.
- **Счётчик** показывает **«Выбрано: N»** — количество выбранных товаров.
- **«Удалить выбранные»** — удаляет все выбранные товары. Требует подтверждения.
- **«Удалить все»** — удаляет все товары в списке. Видна только вне режима выделения, если список не пуст. Требует подтверждения.
- **«Отменить»** — выход из режима выделения и очистка выбора.
- При входе в режим выделения открытая форма редактирования закрывается.

### Создание продукта

1. Нажмите **«+ Новый продукт»**.
2. Откроется боковая панель с формой.

### Форма продукта

| Поле                   | Описание                                       | Обязательное |
|------------------------|-------------------------------------------------|:---:|
| Название               | Наименование продукта                          | Да  |
| Категория              | Категория продукта (из справочника)             | Да  |
| Бренд                  | Название бренда                                 | Нет |
| Поставщик              | Магазин или поставщик                           | Нет |
| Ед. в рецепте          | Единица измерения, используемая в рецептах      | Да  |
| Ед. покупки            | Единица измерения при покупке                   | Да  |
| Цена (руб.)            | Цена за единицу покупки                         | Нет  |
| Коэф. конвертации      | Коэффициент пересчёта из единиц рецепта в единицы покупки | Да |

**Доступные единицы измерения:** г (граммы), кг (килограммы), мл (миллилитры), л (литры), шт (штуки), кор (коробки), уп (упаковки).

**Пример коэффициента конвертации:** если в рецепте используются граммы, а покупка в килограммах, коэффициент конвертации = 1000 (1 кг = 1000 г).

**Автоматический расчёт коэффициента:** если вы выбираете единицы из одной группы измерений (вес: г/кг, объём: мл/л), коэффициент пересчёта рассчитывается автоматически. Поле при этом становится недоступным для редактирования и отображает справку **«Рассчитан автоматически»**. Если единицы из разных групп (например, г и шт), поле остаётся редактируемым для ручного ввода.

### Редактирование и удаление

- Нажмите на строку продукта в таблице — откроется форма редактирования.
- Для сохранения изменений нажмите **«Сохранить»**.
- Для удаления нажмите **«Удалить»** и подтвердите действие в диалоговом окне.
- После сохранения или удаления боковая панель с формой автоматически закрывается.

## 4. Рецепты

Раздел **«Рецепты»** служит для создания и управления рецептами блюд.

### Список рецептов

- Таблица с колонками: **Название**, **Категория**, **Порций**, **Вес** (г).
- Поддерживаются поиск по названию и сортировка по колонкам.

#### Выбор и массовое удаление

- **«Выбрать»** — включить режим выделения. Рядом с каждым рецептом появляются галочки.
- Флажок в заголовке таблицы выбирает/снимает выделение со всех рецептов одновременно.
- Клик на строку или её галочку переключает выбор. Выделенные строки подсвечиваются синим фоном.
- **Счётчик** показывает **«Выбрано: N»** — количество выбранных рецептов.
- **«Удалить выбранные»** — удаляет все выбранные рецепты. Требует подтверждения.
- **«Удалить все»** — удаляет все рецепты в списке. Видна только вне режима выделения, если список не пуст. Требует подтверждения.
- **«Отменить»** — выход из режима выделения и очистка выбора.
- При входе в режим выделения открытая форма редактирования закрывается.

### Создание рецепта

1. Нажмите **«+ Новый рецепт»**.
2. Откроется боковая панель с формой.

### Форма рецепта

| Поле                    | Описание                                    | Обязательное |
|-------------------------|---------------------------------------------|:---:|
| Название                | Название рецепта                            | Да  |
| Категория               | Категория рецепта (из справочника)           | Да  |
| Порций                  | Количество стандартных порций (по умолчанию 4) | Да  |
| Вес готового блюда (г)  | Масса готового блюда в граммах               | Нет |

### Ингредиенты

Раскрывающаяся секция **«Ингредиенты»**. Для каждого ингредиента задаётся:

- **Продукт** — выбор из каталога продуктов. В выпадающем списке внизу (после разделителя) есть опция **«+ Создать новый продукт...»**. Нажмите её, чтобы создать новый продукт прямо из формы рецепта. Откроется модальное окно **«Новый продукт»** с полной формой создания. После сохранения новый продукт автоматически назначится текущему ингредиенту, единица измерения рецепта будет заполнена из настроек продукта, а количество установится по умолчанию (100 для граммов, 1 для остальных).
- **Количество** — числовое значение.
- **Единица** — подставляется автоматически из настроек продукта.

Кнопки управления:
- **«+ Добавить»** — добавить строку ингредиента.
- **×** (крестик справа от каждой строки) — удалить этот конкретный ингредиент. Клик происходит без подтверждения.

**Порядок ингредиентов:** ингредиенты сохраняют порядок, в котором вы их расположили. При редактировании рецепта они отображаются в сохранённом порядке. При сохранении порядковые номера присваиваются автоматически.

### Шаги приготовления

Раскрывающаяся секция **«Шаги приготовления»**. Шаги отображаются нумерованным списком.

**Добавление шага:**
1. Введите описание шага в поле ввода.
2. Нажмите **«+»** или клавишу **Enter**.

**Редактирование шага:**
1. Наведите курсор на шаг — появится кнопка **✎**.
2. Нажмите на неё — текст станет редактируемым.
3. Внесите изменения и нажмите **Enter** или кликните за пределами поля для сохранения.

**Удаление шага:** нажмите **«−»** для удаления последнего шага.

### Сохранение и удаление

- **«Сохранить»** — сохраняет рецепт и закрывает панель.
- **«Удалить»** (только для существующих рецептов) — удаление с подтверждением.

## 5. Планировщик меню

Основной экран приложения. Позволяет составить меню на неделю, распределив блюда и продукты по дням и приёмам пищи.

### Структура экрана

Экран разделён на три области:

1. **Левая панель** — список сохранённых меню.
2. **Центральная область** — сетка планирования (7 дней × 3 приёма пищи).
3. **Правая панель** — панель-источник с рецептами и продуктами для перетаскивания.

### Управление меню

#### Создание нового меню

1. В левой панели нажмите **«+ Новое меню»**.
2. В диалоговом окне введите название меню.
3. Нажмите **«Подтвердить»**.

#### Выбор меню

Нажмите на название меню в левой панели. Сетка заполнится содержимым выбранного меню.

#### Удаление меню

Нажмите **«Удалить»** в левой панели и подтвердите действие.

### Сетка планирования

Сетка состоит из ячеек, где:

- **Столбцы** — дни недели: Пн, Вт, Ср, Чт, Пт, Сб, Вс.
- **Строки** — приёмы пищи: Завтрак, Обед, Ужин.

Сетка растягивается на всю доступную высоту экрана.

#### Добавление блюда или продукта в ячейку

1. В правой панели выберите вкладку **«Блюда»** (рецепты) или **«Ингредиенты»** (продукты).
2. При необходимости используйте поиск для фильтрации списка.
3. Перетащите (drag & drop) нужный элемент в ячейку сетки.

При добавлении:
- **Рецепт** — количество порций рассчитывается автоматически: суммируются коэффициенты порций всех членов семьи. Например, если в семье мама (×1.0), папа (×1.0) и ребёнок (×0.5), будет установлено 2.5 порции.
- **Продукт** — количество устанавливается равным 1 в единице рецепта продукта.

#### Отображение элементов в ячейке

Каждый элемент в ячейке отображается с цветовой маркировкой:
- **Рецепты** — голубой фон с синей полосой слева. Показывает название и количество порций (например, «2.5 п.»).
- **Продукты** — оранжевый фон с оранжевой полосой слева. Показывает название и количество с единицей (например, «1 г»).

#### Перемещение элементов между ячейками

Вы можете перетащить элемент из одной ячейки в другую (например, из Понедельника Завтрак в Среду Ужин). При наведении на целевую ячейку она подсвечивается синей границей. Элемент сохраняет все свои данные (количество, количество порций) при перемещении.

#### Сортировка элементов в ячейке

Вы можете перетащить элемент в пределах одной ячейки, чтобы изменить его порядок. При перетаскивании элемент отображается с прозрачностью (ghost эффект). Порядок сохраняется при сохранении меню.

#### Изменение количества

Нажмите на элемент в ячейке — откроется диалог:
- Для рецептов: **«Порции»** — введите нужное количество порций.
- Для продуктов: **«Количество»** — введите нужное количество.

#### Удаление элемента из ячейки

Наведите курсор на элемент и нажмите кнопку **×** справа.

### Панель-источник (правая)

#### Информация о семье

В верхней части правой панели отображается состав семьи с коэффициентами порций:
```
• Мама (×1)
• Папа (×1)
• Ребёнок (×0.5)
```

#### Вкладки

- **Блюда** — список всех рецептов. Перетаскивайте в ячейки сетки.
- **Ингредиенты** — список всех продуктов. Перетаскивайте в ячейки сетки.

Каждая вкладка имеет поле поиска для фильтрации списка.

### Действия с меню

Кнопки под сеткой:

| Кнопка                          | Действие                                           |
|---------------------------------|----------------------------------------------------|
| Сохранить                       | Сохраняет текущее меню                              |
| Очистить                        | Удаляет все элементы из сетки (с подтверждением)    |
| Сформировать список покупок      | Генерирует список покупок и переходит к нему        |

## 6. Список покупок

Формируется автоматически из выбранного меню. Содержит все необходимые продукты с расчётом количества и стоимости.

### Формирование списка

В Планировщике меню нажмите **«Сформировать список покупок»**. Приложение автоматически:
- соберёт все ингредиенты из рецептов с учётом количества порций;
- сгруппирует одинаковые продукты, суммируя количества;
- пересчитает количества из единиц рецепта в единицы покупки;
- рассчитает стоимость каждой позиции и итоговую сумму.

### Таблица покупок

Продукты сгруппированы по категориям. Для каждого продукта отображается:
- **Флажок** — отметка о покупке.
- **Название** — наименование продукта.
- **Количество** — в единицах покупки (при необходимости с указанием единиц рецепта в скобках).
- **Стоимость** — расчётная стоимость в рублях.

#### Отметка о покупке

Нажмите флажок слева от продукта. Купленные позиции отображаются зачёркнутым текстом с зелёным фоном.

#### Изменение количества

Нажмите на ячейку количества — откроется диалог редактирования.

#### Выбор и массовое удаление

- **«Выбрать»** — включить режим выделения. Рядом с каждым товаром появляются галочки.
- Флажок в заголовке таблицы выбирает/снимает выделение со всех товаров одновременно.
- Клик на строку или её галочку переключает выбор. Выделенные строки подсвечиваются синим фоном.
- **Счётчик** показывает **«Выбрано: N»** — количество выбранных товаров.
- **«Удалить выбранные»** — удаляет все выбранные товары из списка. Требует подтверждения.
- **«Удалить все»** — очищает весь список покупок. Видна только вне режима выделения, если список не пуст. Требует подтверждения.
- **«Отменить»** — выход из режима выделения и очистка выбора.

### Итоги и экспорт (правая панель)

#### Сумма корзины

- Общая стоимость всех позиций.
- Количество позиций в списке.
- Прогресс покупок: полоса прогресса с числом купленных позиций из общего количества.

#### Дополнительные действия

| Кнопка                  | Действие                                                    |
|-------------------------|-------------------------------------------------------------|
| Удалить из списка        | Удаляет выбранный продукт из списка (с подтверждением)       |
| Экспорт (текст)          | Открывает окно с текстовой версией списка для копирования   |
| Экспорт (CSV)            | Скачивает файл `shopping_list.csv`                          |

#### Добавление продукта вручную

В секции **«Добавить продукт»** правой панели:
1. Выберите продукт из выпадающего списка.
2. Укажите количество.
3. Нажмите **«Добавить в список»**.

## 7. Настройки

Раздел настроек доступен через боковую панель. Содержит следующие подразделы:

### 7.1. Члены семьи

Управление составом семьи. Коэффициенты порций членов семьи используются для автоматического расчёта количества порций при добавлении рецепта в меню.

| Поле                 | Описание                                              | Обязательное |
|----------------------|-------------------------------------------------------|:---:|
| Имя                  | Имя члена семьи                                       | Да  |
| Коэф. порции         | Множитель порции (1.0 — стандарт, 0.5 — половина, 2.0 — двойная) | Да |
| Ограничения          | Диетические ограничения (произвольный текст)           | Нет |
| Комментарий          | Дополнительные заметки                                 | Нет |

Диапазон коэффициента порции: от 0.1 до 5.0, шаг 0.1.

При регистрации нового пользователя автоматически создаётся первый член семьи с его именем и коэффициентом порции 1.0.

### 7.2. Категории продуктов

Справочник категорий для организации продуктов (например: «Молочные», «Мясо», «Крупы»).

**Создание:** нажмите **«+ Добавить»** и введите название.

**Скрытие активной категории:**
- Нажмите **«Скрыть»** рядом с категорией.
- Требует подтверждения.
- Скрытая категория получает статус **«Скрыта»** и перестаёт отображаться в выпадающих списках при создании новых продуктов.

**Удаление:**
- Если категория не используется в продуктах или рецептах — удаляется полностью.
- Если категория используется — появляется специальное диалоговое окно **«Категория используется»** с сообщением **«Эта категория привязана к записям. Что сделать?»** и тремя вариантами:
  - **«Отмена»** — отменить операцию.
  - **«Скрыть»** — категория скрывается; существующие товары сохранят её, но новые товары не смогут её использовать.
  - **«Удалить полностью»** — категория удаляется окончательно.

**Восстановление:** скрытая категория (статус «Скрыта») может быть восстановлена кнопкой **«Активировать»**.

### 7.3. Категории рецептов

Аналогично категориям продуктов, но для рецептов (например: «Супы», «Выпечка», «Салаты»).

Поддерживает те же операции:
- **Скрытие активной категории** через кнопку **«Скрыть»** с подтверждением.
- **Удаление** с автоматическим выбором типа операции в зависимости от использования категории.
- **Восстановление** скрытой категории кнопкой **«Активировать»**.

### 7.4. Настройки аккаунта

#### Смена пароля

1. Введите **текущий пароль**.
2. Введите **новый пароль** (минимум 6 символов).
3. **Повторите новый пароль** — должен совпадать.
4. Нажмите **«Сменить пароль»**.

При неверном текущем пароле отобразится сообщение об ошибке.

## 8. Типичные сценарии использования

### Сценарий 1: Первоначальная настройка

1. Зарегистрируйтесь в приложении.
2. Перейдите в **Настройки → Члены семьи**. Ваш аккаунт уже добавлен как первый член семьи. Добавьте остальных членов семьи с нужными коэффициентами порций.
3. Перейдите в **Настройки → Категории продуктов** и создайте категории (например: «Молочные», «Мясо», «Овощи», «Крупы»).
4. Перейдите в **Настройки → Категории рецептов** и создайте категории (например: «Супы», «Вторые блюда», «Салаты», «Выпечка»).
5. Перейдите в **Продукты** и добавьте продукты с указанием единиц измерения, цен и коэффициентов конвертации.
6. Перейдите в **Рецепты** и создайте рецепты, добавив ингредиенты из каталога продуктов и шаги приготовления.

### Сценарий 2: Планирование меню на неделю

1. Откройте **Планировщик меню**.
2. Нажмите **«+ Новое меню»** и введите название (например, «Неделя 12 марта»).
3. Из правой панели перетащите рецепты и продукты в нужные ячейки сетки (день недели × приём пищи).
4. Порции рассчитаются автоматически на основе состава семьи. При необходимости скорректируйте количество, нажав на элемент в ячейке.
5. Нажмите **«Сохранить»**.

### Сценарий 3: Формирование списка покупок

1. В Планировщике меню выберите нужное меню.
2. Нажмите **«Сформировать список покупок»**.
3. Приложение рассчитает все необходимые продукты, сгруппирует их по категориям и посчитает стоимость.
4. При необходимости добавьте дополнительные продукты вручную.
5. Экспортируйте список в текстовый формат или CSV для удобства использования в магазине.
6. Во время покупок отмечайте купленные позиции флажком.

### Сценарий 4: Повторное использование меню

1. Откройте **Планировщик меню**.
2. В левой панели выберите ранее сохранённое меню.
3. При необходимости внесите изменения (замените блюда, скорректируйте порции).
4. Сформируйте новый список покупок.
